INTRODUCTION                   *conjure-client-common-lisp-swank-introduction*

Connecting Common Lisp to Conjure is an easy process if you have used swank,
emacs, or quicklisp before.

Firstly, set up Common Lisp and Quick Lisp as normal.

Open up the CL REPL in another terminal, then type the following code:
>
  (ql:quickload :swank)
  (swank:create-server :dont-close t)

You should now have a swank server started, listening on port `4005`. This is
the default port that conjure will use.

Now simply open up any `.lisp` file in conjure, and it will automatically
connect to swank.
>
 * https://common-lisp.net/

MAPPINGS                           *conjure-client-common-lisp-swank-mappings*

These mappings are the defaults, you can change them as described in
|conjure-mappings| and |conjure-configuration|.

See |conjure-client-common-lisp-swank-configuration| for specific
configuration options relevant to these mappings.

<localleader>cc          Connect to a running swank REPL.

<localleader>cd          Disconnect from the REPL.

<localleader>dr          Invoke a restart of the debugger by number. When an
                         evaluation signals an unhandled condition or calls
                         `(break)`, the log shows the condition, the numbered
                         restarts and the backtrace. Other evaluations keep
                         working while the debugger waits.
<localleader>ss          Toggle a sticker on the form under the cursor. When
                         an evaluation contains a stickered form, every pass
                         through it records the values it returns. The
                         latest values show as virtual text after the form.

<localleader>sl          Log every value recorded by the stickers in the
                         buffer.

<localleader>sc          Remove all stickers from the buffer.
<localleader>hs          Open the local HyperSpec page for the symbol under
                         the cursor. Needs
                         |g:conjure#client#common_lisp#swank#hyperspec_root|.
<localleader>m1          Macroexpand the form under the cursor once
                         (`swank:swank-macroexpand-1`) and show the result
                         in the log.

<localleader>ma          Fully macroexpand the form under the cursor
                         (`swank:swank-macroexpand-all`) and show the result
                         in the log.

CONFIGURATION                 *conjure-client-common-lisp-swank-configuration*

All configuration can be set as described in |conjure-configuration|.


                            *g:conjure#client#common_lisp#swank#mapping#start*
`g:conjure#client#common_lisp#swank#mapping#connect`
            Connect to a running swank REPL.
            Default: `"cc"`

                             *g:conjure#client#common_lisp#swank#mapping#stop*
`g:conjure#client#common_lisp#swank#mapping#disconnect`
            Disconnect from the REPL.
            Default: `"cd"`

                  *g:conjure#client#common_lisp#swank#connection#default_host*
`g:conjure#client#common_lisp#swank#connection#default_host`
            The default swank host to connect to.
            Default: `"127.0.0.1"`

                  *g:conjure#client#common_lisp#swank#connection#default_port*
`g:conjure#client#common_lisp#swank#connection#default_port`
            The default swank port to connect to.
            Default: `"4005"`

                       *g:conjure#client#common_lisp#swank#enable_completions*
`g:conjure#client#common_lisp#swank#enable_completions`
            Enable completion suggestions through tree sitter and via swank
            simple-completions.

            Example value:
                     `false`

            Default: `true`

                   *g:conjure#client#common_lisp#swank#mapping#invoke_restart*
`g:conjure#client#common_lisp#swank#mapping#invoke_restart`
            Prompt for a restart number and invoke it in the innermost
            debugger level.
            Default: `"dr"`
                   *g:conjure#client#common_lisp#swank#mapping#sticker_toggle*
`g:conjure#client#common_lisp#swank#mapping#sticker_toggle`
            Toggle a sticker on the current form.
            Default: `"ss"`

                     *g:conjure#client#common_lisp#swank#mapping#sticker_list*
`g:conjure#client#common_lisp#swank#mapping#sticker_list`
            Log every value recorded by the stickers.
            Default: `"sl"`

                    *g:conjure#client#common_lisp#swank#mapping#sticker_clear*
`g:conjure#client#common_lisp#swank#mapping#sticker_clear`
            Remove all stickers from the buffer.
            Default: `"sc"`
                        *g:conjure#client#common_lisp#swank#mapping#hyperspec*
`g:conjure#client#common_lisp#swank#mapping#hyperspec`
            Open the local HyperSpec page for the symbol under the cursor.
            Default: `"hs"`

                          *g:conjure#client#common_lisp#swank#hyperspec_root*
`g:conjure#client#common_lisp#swank#hyperspec_root`
            Directory of a local copy of the Common Lisp HyperSpec, the one
            that contains `Data/Map_Sym.txt`. Symbols are resolved through
            that file and the page is opened with |vim.ui.open()|.

            Example value:
                     `"~/localdocs/hyperspec"`

            Default: unset
                    *g:conjure#client#common_lisp#swank#mapping#macroexpand_1*
`g:conjure#client#common_lisp#swank#mapping#macroexpand_1`
            Macroexpand the current form once.
            Default: `"m1"`

                  *g:conjure#client#common_lisp#swank#mapping#macroexpand_all*
`g:conjure#client#common_lisp#swank#mapping#macroexpand_all`
            Fully macroexpand the current form.
            Default: `"ma"`
